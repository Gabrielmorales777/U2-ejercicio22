# U2-ejercicio22
## Pasarelas de Pago Multicanal

**Objetivo principal:** Aplicar abstracción, interfaces y polimorfismo en Java para desarrollar un sistema de pagos flexible y desacoplado.

**Descripción:** Se desarrolla un sistema de procesamiento de pagos que permite realizar transacciones mediante tarjetas de crédito, criptomonedas y billeteras virtuales. Se utiliza la interfaz `ProcesadorPago` para establecer un comportamiento común entre las distintas pasarelas, mientras que `ModuloCompras` permite cambiar dinámicamente el medio de pago sin modificar su lógica interna.
